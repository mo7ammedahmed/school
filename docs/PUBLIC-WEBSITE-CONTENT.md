# إدارة محتوى الموقع العام

افتح **التواصل ← صفحات الموقع** (`/content/pages`) بحساب لديه صلاحية `manage-content` في المدرسة المختارة.

## الصفحات الأساسية

تظهر ثماني بطاقات: الرئيسية، عن المدرسة، البرامج، القبول، المرافق، فريق المدرسة، التواصل، والأسئلة الشائعة. اختر **إعداد المحتوى** لإنشاء مسودة، أو **تعديل** إذا كانت الصفحة موجودة. عند النشر يستبدل المحتوى المحرر محتوى الصفحة الأساسية في عنوانها الحالي. تبقى الصفحة الحالية متاحة إلى أن تنشر البديل.

## كتابة المحتوى

1. اكتب العنوان والنص التعريفي بالعربية والإنجليزية. عند غياب نص بإحدى اللغتين يعرض الموقع النص المتاح.
2. أضف أقسامًا: قسم افتتاحي، نص تعريفي، بطاقات مزايا، حقائق وأرقام، أخبار، فعاليات، برامج، فريق المدرسة، أسئلة وأجوبة، أو دعوة لاتخاذ إجراء.
3. أدخل عناوين الأقسام وأوصافها، وأضف عناصر البطاقات والأرقام والأسئلة. للأزرار استخدم رابطًا محليًا مثل `/apply` أو رابط HTTPS.
4. رتّب الأقسام بأزرار أعلى/أسفل. ألغِ **ظاهر في الصفحة** لإخفاء قسم مع الاحتفاظ به داخل المحرر. لا تصل بيانات الأقسام المخفية إلى الزوار.
5. احفظ **مسودة — خاصة**، ثم افتح **معاينة الصفحة المحفوظة**. المعاينة تعرض ما حفظته، وتتطلب صلاحية إدارة المحتوى؛ لا تعمل كرابط مشاركة عام.
6. اختر **منشورة** واحفظ لإظهار الصفحة، أو **نشر مجدول** وحدد الموعد بتوقيت جهازك. يظهر المحتوى المجدول تلقائيًا بعد الموعد عند طلب الصفحة، دون مهمة إضافية.

أقسام الأخبار والفعاليات تجلب المحتوى المنشور الخاص بالمدرسة. يمكن كتابة بطاقات البرامج والفريق والأسئلة يدويًا من المحرر. إذا تركت عناصر هذه الأقسام فارغة فإنها تعرض السجلات العامة الحالية؛ قائمة الفريق التلقائية تعرض ملفات الموظفين المميزة فقط. إضافة عناصر مخصصة تستبدل القائمة التلقائية داخل القسم، فلا تظهر أسئلة أو أسماء إضافية خارج تحكم المحرر.

## إضافة صفحات جديدة

اختر **إضافة صفحة**، واترك **الصفحة العامة** على **صفحة إضافية**. أدخل عنوان رابط فريدًا مثل `school-life`، فتظهر الصفحة بعد نشرها في `/pages/school-life`. فعّل **إظهار الصفحة في قائمة الموقع بعد نشرها** وحدد الترتيب. تظهر الصفحات الإضافية المنشورة في قائمة **المزيد** على سطح المكتب، وقائمة الهاتف وتذييل الموقع.

المسودة، والمؤرشفة، والمنشورة بموعد مستقبلي لا تظهر للزوار أو في القائمة. تحويل صفحة أساسية إلى مسودة أو أرشيف يعيد محتواها العام الافتراضي. تعديل صفحة منشورة ثم حفظها يغيّر المحتوى العام مباشرة؛ هذه النسخة لا تحتفظ بمسودة مستقلة من الصفحة المنشورة.

## بيانات المدرسة والتواصل

يتبع اسم المدرسة إعدادات المدرسة المختارة. عدّل بريد المدرسة وهاتفها وعنوانها في **الإعدادات ← المدرسة**؛ يستخدمها تذييل الموقع بدل بيانات الاتصال الثابتة. تحتفظ صفحة التواصل بنموذج إرسال الرسائل إلى المدرسة حتى عند تخصيص محتواها.

## النشر على Laravel Cloud

التغيير يتضمن migration لإضافة النص العربي وخيارات قائمة الموقع. يلزم تشغيل `php artisan migrate --force` ضمن خطوات النشر المعتادة وبناء الواجهة وSSR باستخدام `npm run build` قبل تشغيل النسخة الجديدة. الترحيل أضيف دون تغيير الصفحات الموجودة أو نشر محتوى تلقائيًا.

لا تنشر أرقامًا أو مزايا أو أسماء موظفين قبل تأكيد صحة المعلومات وموافقة المدرسة على نشرها.
